## What is CIDR?

CIDR (Classless Inter-Domain Routing) is a method used to divide IP addresses into network and host portions.

Example:

192.168.29.105/24

IP Address:
192.168.29.105

CIDR:
/24

Host Bits:
32 - 24 = 8

Total IP Addresses:
2^8 = 256

Usable Hosts:
254
