# Commands Used

## hostname -I

Displays the private IP address.

```bash
hostname -I
```

---

## ip a

Displays all network interfaces and IP addresses.

```bash
ip a
```

---

## ip route

Displays the routing table and network information.

```bash
ip route
```

---

## ipcalc

Calculates subnet information.

```bash
ipcalc <your-private-ip>/24
```
