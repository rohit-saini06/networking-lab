# Networking Day 5

## Topic

TCP, UDP and Ports

## TCP

Reliable communication protocol.
Ensures packet delivery and maintains packet order.

Examples:
- HTTP
- HTTPS
- SSH

## UDP

Fast communication protocol.
Does not guarantee delivery.

Examples:
- DNS
- Video Streaming
- Online Games

## Port

A Port identifies a specific service running on a device.

Example Ports

22 - SSH

80 - HTTP

443 - HTTPS

53 - DNS

3306 - MySQL

5432 - PostgreSQL

## Summary

Today I learned:

- Difference between TCP and UDP
- What is a Port
- How to check listening ports
- How to identify services using ports
