# Networking Day 4

## Topic

MAC Address and ARP

## What is MAC Address?

A MAC (Media Access Control) Address is a unique hardware address assigned to every network interface card (NIC).

Example:

08:00:27:8a:4c:92

## What is ARP?

ARP (Address Resolution Protocol) is used to find the MAC Address of a device using its IP Address.
