# Commands Used

## ip link

Displays all network interfaces and their MAC addresses.

```bash
ip link
```

---

## ip neigh

Displays the ARP table.

```bash
ip neigh
```

---

## ping -c 3 google.com

Checks network connectivity.

```bash
ping -c 3 google.com
```

---

## cat /sys/class/net/*/address

Displays MAC addresses of all network interfaces.

```bash
cat /sys/class/net/*/address
```
