# Commands Used

## 1

```bash
hostname -I
```

Purpose:
Shows the private IP address.

---

## 2

```bash
ip a
```

Purpose:
Displays all network interfaces and IP addresses.

---

## 3

```bash
ping google.com
```

Purpose:
Checks internet connectivity and packet communication.

---

## 4

```bash
curl ifconfig.me
```

Purpose:
Displays the public IP address.
