# Networking Day 1

## Topic
- IP Address

## Definition

An IP Address (Internet Protocol Address) is a unique address assigned to every device on a network so that devices can communicate with each other.

## In Simple Words

Just like every house has a unique address, every device connected to a network has an IP address.

## Practical Commands

- hostname -I
- ip a
- ping google.com
- curl ifconfig.me

## Observation

Today I learned how to identify my system's IP address, check internet connectivity, and view network interface information.
