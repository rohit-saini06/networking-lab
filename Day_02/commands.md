# Commands Used

## 1. hostname

```bash
hostname
```

Purpose:
Displays the hostname of the system.

---

## 2. ip link

```bash
ip link
```

Purpose:
Displays all available network interfaces.

---

## 3. ip route

```bash
ip route
```

Purpose:
Shows the routing table and default route.

---

## 4. cat /etc/resolv.conf

```bash
cat /etc/resolv.conf
```

Purpose:
Displays the DNS server configuration.

---

## 5. ip route | grep default

```bash
ip route | grep default
```

Purpose:
Shows the default gateway used by the system.
