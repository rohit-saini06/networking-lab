## What is OSI Model?

OSI (Open Systems Interconnection) is a reference model that explains how data travels from one device to another through seven layers.

## OSI Layers

7. Application
6. Presentation
5. Session
4. Transport
3. Network
2. Data Link
1. Physical

## Important Layers for DevOps

Application Layer
- HTTP
- HTTPS
- DNS
- SSH

Transport Layer
- TCP
- UDP

Network Layer
- IP Address
- Router
